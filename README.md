## 👩‍💻 About Me

I'm a **Data Engineering Trainee** based in **Hyderabad, India**, with a **Bachelor of Technology** in Computer Science (Data Science).

- 🔭 I build **end-to-end data pipelines** using **AWS S3, Snowflake, and dbt**, covering data modeling, ETL/ELT transformations, and dimensional modeling (**SCD Type 2**).

## 🚀 Featured Projects

### 📦 Customer Sales Data Engineering & Analytics Pipeline
![AWS S3](https://img.shields.io/badge/AWS%20S3-569A31?style=flat-square&logo=amazons3&logoColor=white)
![PySpark](https://img.shields.io/badge/PySpark-E25A1C?style=flat-square&logo=apachespark&logoColor=white)
![Databricks](https://img.shields.io/badge/Databricks-FF3621?style=flat-square&logo=databricks&logoColor=white)
![SQL](https://img.shields.io/badge/SQL-4479A1?style=flat-square&logo=postgresql&logoColor=white)
![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logo=powerbi&logoColor=black)

Designed an **end-to-end pipeline** that moves raw sales data from cloud storage straight into Databricks for seamless large-scale processing.

- 🏗️ Adopted the **Medallion Architecture** to turn messy raw data into production-ready assets across **Bronze, Silver, and Gold** tiers.
- 🧹 Resolved data quality issues with **PySpark and SQL**: removed duplicates, handled null values, and built derived metrics.
- 📐 Modeled the final layers so analysts can easily query **product popularity, customer habits, and overall revenue**.
- 📊 Built interactive **Power BI dashboards** that give stakeholders a clear, actionable view of business health and KPIs.

### 🛒 Walmart Sales Analysis
![SQL](https://img.shields.io/badge/SQL-4479A1?style=flat-square&logo=postgresql&logoColor=white)
![Power BI](https://img.shields.io/badge/Power%20BI-F2C811?style=flat-square&logo=powerbi&logoColor=black)

Analyzed sales data across **45 Walmart stores** using SQL and Power BI to identify sales trends and store performance.

- 🔍 Performed **data cleaning, validation, and EDA** to uncover seasonal patterns and measure how economic factors (**CPI, unemployment, fuel price**) affect weekly sales.
- 📈 Built interactive **Power BI dashboards** tracking KPIs such as **total sales, average weekly sales, and store rankings**.
